## Issues Encountered & Solutions

### Claude Code not found in Cursor Extensions
- **Issue:** Claude Code extension was not available in Cursor's Marketplace when searching "Claude Code"
- **Solution:** Installed Claude Code via terminal instead using `npm install -g @anthropic-ai/claude-code`. Successfully launched with the `claude` command.

### Claude Code login requires subscription
- **Issue:** Logging into Claude Code requires a Claude Pro or Max subscription
- **Solution:** Installation was completed successfully; login step requires paid subscription.

### Codex not found in Cursor Marketplace
- **Issue:** Codex add-on was not found when searching in Cursor's Marketplace
- **Solution:** Searched using multiple terms but no results appeared. The extension may no longer be available or may have been renamed.
